  • Dominio:

    • se refiere al nombre de dominio de un sitio web, que es la dirección que los usuarios escriben en la barra de navegación para acceder a un sitio web específico.

  • Subdominio

    • dirección que se añade a un dominio principal para crear una sección separada dentro del mismo sitio web.

  • URL:

    es la dirección de un recurso específico en la web, como una página web, una imagen o un archivo.

  • DNS

    • "Domain Name System" (Sistema de Nombres de Dominio), es como la guía telefónica de Internet

  • Hosting:

    es el servicio que te permite almacenar y publicar los archivos de tu sitio web en internet

  • FTP:

    • es un protocolo de red que permite la transferencia de archivos entre sistemas en una red, especialmente Internet

  • HTTP:

    es un protocolo de comunicación utilizado para la transferencia de datos en la web

  • HTTPS:

    Hypertext Transfer Protocol Secure", es la versión segura de HTTP, el protocolo que permite la comunicación entre un navegador web y un sitio web

  • W3C:

    • es una comunidad internacional sin fines de lucro que desarrolla estándares para la Web

  • UTF-8:

    • estándar de codificación de caracteres que permite representar cualquier carácter Unicode utilizando entre 1 y 4 bytes

  • HTMLS y su estructura:

    • Lenguaje de marcado estándar utilizado para crear páginas web
